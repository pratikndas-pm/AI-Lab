🚀 Lead Scoring API is Live

Serverless FastAPI on Vercel · part of Pratik N Das’ AI Lab

Base Endpoints

  • /api → health check
  • /api/score → POST JSON to get win probability + explanation
  • /api/docs → Swagger UI
Open /api Open Swagger

Example Request

POST /api/score
Content-Type: application/json

{
  "budget": 30000,
  "is_enterprise": true,
  "touches": 3,
  "days_to_first_reply": 1
}

Response → {"win_probability": 0.81, "explanation": "...", "inputs": {...}}

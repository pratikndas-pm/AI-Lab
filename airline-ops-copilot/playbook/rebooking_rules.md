# Rebooking Rules & Procedures

## Automatic Rebooking Triggers
- **Misconnection**: Connection time < minimum connection time (MCT)
- **Flight cancellation**: All passengers
- **Delay > 3 hours**: Offer alternative flights
- **Aircraft swap**: If downgrade or seat unavailability

## Rebooking Priority Order
1. Same airline, same day
2. Same airline, next available
3. Partner airline, same day
4. Partner airline, next day
5. Interline agreement airlines

## Booking Class Rules
- **Protect original booking class** when possible
- **One class downgrade permitted** if no alternative
- **Voluntary upgrades**: Not standard practice in IROP
- **Involuntary downgrades**: Require compensation

## Connection Protection
- **Minimum Connection Time (MCT)**: Typically 60-90 minutes domestic, 90-120 international
- **If new connection < MCT**: Find alternative routing
- **Maximum connection time**: Avoid connections > 6 hours unless overnight
- **Direct flights**: Always preferred over connections when available

## Special Passenger Handling
- **Groups (10+ passengers)**: Keep together if possible, split only if necessary
- **Families with children**: Priority to keep together
- **Through-checked baggage**: Ensure bag tags updated with new flights
- **Pets in cargo**: Must travel on same flight as owner

## DO NOT Rebook If:
- Passenger is no-show
- Passenger requested voluntary change (not IROP)
- Passenger caused their own misconnection (late to gate)
- Alternative would arrive later than original

## Rebooking Documentation
- Record: Original flight, new flight, reason, agent ID, timestamp
- Update PNR with IROP code
- Tag baggage with new routing
- Issue new boarding passes
